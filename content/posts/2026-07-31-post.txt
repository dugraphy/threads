실제 보고되는 사례 기준으로 정리하면 이래요 👇

1. 보안 취약점
입력값 검증, 인증 로직이 누락되어 URL 파라미터 조작만으로 타 사용자 데이터 접근이 가능한 사례가 다수 보고가 있음

2. 성능 저하
불필요한 API 중복 호출, 이미지 미최적화 등으로 트래픽 증가 시 응답속도가 급격히 저하되는 구조적인 문제

3. 확장성 부족
비효율적인 데이터베이스 쿼리 설계로 인해 사용자 수 증가 시 서버 다운으로 이어지는 경우

4. 유지보수 비용 증가
일관성 없는 코드 구조로 인해 기능 추가·수정 시 전체 리팩토링이 필요한 상황 발생

AI는 초기 개발 속도는 무시할 수 없지만 이후 보안·성능·확장성 검증은 별도의 전문적인 검토 과정이 필요한거 같아요!
